# Troubleshooting

- Cinco clipes não encontrados: use storage/manual_input/ID/segment_01.mp4 até segment_05.mp4.
- Clipes recusados: cada um deve ser vertical, ter áudio e duração aproximada de oito segundos.
- OAuth ausente: execute python -m app.cli youtube-auth depois de instalar o JSON do OAuth.
- Estado da produção: consulte python -m app.cli status ID.
